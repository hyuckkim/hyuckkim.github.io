## Vision AI가 뭔가요
공장이라면 육안 검사를 대체하는 검사기를 원할것
 -> Vision AI

육안 검사 -> 원격 검사 -> rule-base 이미지 분석 -> AI
DAP -> AGENT 등등등으로 발전한다.

인공지능은 항상 과도기지만 여기는 더 과도기.
생성형으로 바꾸면 성공률이 99.9%도 가능하다!  
but 높은 단계 기술은 오래걸림
 : 100ms 미만으로 깎아야 한다던가...
 이럴경우 사용 불가능할수도 있음 (tradeoff)

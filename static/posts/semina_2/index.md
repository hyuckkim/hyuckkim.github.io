이하 내용.

## 영포티
밈에서와 달리...
- 의사결정자가 됨 (팀장, PM, 임원 ...)
- 문서를 좋아하던 이전 세대와는 다르다!
- 비벼야겠지?

## 아날로그 -> 디지털 -> AI 시대
일하는 방식이 어떻게 바뀌는지를 통으로 체감한 사람들임.
'왜 이렇게 말하는지' 에서 알아갈만한 것들이 있음

* 아날로그: 느림의 미학
  연락이 안 된다 -> 약속이 중요함 -> 인내력 상승
* 디지털: 메신저
  정보의 접근 -> 결과 내기 쉬음. 무한 수정
* AI: 초안 만들어줌
  (자료정리, 번역... 신입이 하던 일 대체) -> 사람은 editor.

## AI가 빨라질수록 사람은 더 선명해져야 한다
- 생각: 원리 분석 / 맥락 이해가 중요.
  사고 수습을 해야 하므로...
- 질문: 할 수 있어야 함. 맹신 X. (AI말고도 강연자 등등등)
- 실험: 완벽한 계획보다 앞으로 나가기

## 마치며
- 이것저것 했는데 결과적으로 전부 의미있었음
- 자기 이야기를 할 수 있어야 한다.

## 추가썰
- 방산업체: 보안때문에 GPT를 못쓰니까 AI시대 전으로 돌아간 느낌.
  문서도 직접쓰고 코드도 직접짜고.
  AI에게 종속되었다면 못했을것
- 물류센터: AI로 물류 분석하는 프로그램이 뻑나서 2시간동안 멈췄었다
  알고있어서 그나마 2시간만에 고쳤다. AI를 맹신했다면 못고쳤을것
  2시간 멈추니까 택배가 40만 박스가 쌓였다.
- 머신러닝 깎는 장인: CV분야에서는 여전히 사람이 파라미터 깎아넣는게 유효함
  사실 데이터 많이 준비하는 게 더 중요하긴 함
  사진 만장씩 준비하고.
- 월 결산 자동화: 한달에 4시간 걸리는걸 자동화해야할까...
  사장이 원하는 보여주기식 자동화 (효율은 관계없음) 가 많다
- 지식 서비스: 내부적으로 성능이 그렇게 안 중요한 용어집.
  시니어들 이제 은퇴하면 회사 망하는거 아닌가...?
  라고 생각하는 대표들.
